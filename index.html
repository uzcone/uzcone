🧠 Fashion-MNIST CNN 분류기 데모

Python 및 TensorFlow 기반으로 훈련된 합성곱 신경망(CNN) 모델을 시뮬레이션합니다. 아래 아이템을 선택하면 모델이 이미지 특징을 추출하여 분류 결과를 도출합니다.

예측 클래스: T-shirt / Top
예측 확률(Confidence): 98.4%
* 구조: Conv2D(32) → MaxPool → Conv2D(64) → Dense(128) → Softmax(10)
📌 핵심 학습 내용:
  • 28x28 흑백 이미지 정규화 (0~255 → 0.0~1.0)
  • Dropout(0.25) 적용을 통한 과적합(Overfitting) 방지
  • 테스트 데이터셋 기준 검증 정확도 91.8% 달성
